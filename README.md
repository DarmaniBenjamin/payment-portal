# Payment Portal

Self-hosted payment portal for Grenada, using WiPay as the card gateway.
One core service that WordPress sites, static sites and other apps connect to.

All rights reserved.

## Local setup

1. Install packages: `npm install`
2. Copy `.env.example` to `.env` and fill in your database details
3. Start in dev mode: `npm run dev`
4. Check it works: http://localhost:4000/api/health
